# Security policy

OpenRaceRender is experimental software. Security fixes are developed on `main`; there is no maintained long-term release branch yet.

## Reporting a vulnerability

If GitHub's private vulnerability reporting is available, use **Security → Report a vulnerability** on this repository. Otherwise, open an issue asking the maintainer for a private reporting channel, without including exploit details, secrets, or private files.

Include the affected commit or version, macOS version, a description of the impact, and minimal reproduction steps. Prefer a small synthetic file over a personal session, GPS log, or camera recording. Do not attach credentials or private media to a public report.

Malformed project/telemetry files, parser memory or resource issues, and unexpected execution or file access are relevant reports. Imported Enhanced scripts are currently retained as data and are not executed by OpenRaceRender.
