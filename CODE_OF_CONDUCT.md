# Code of conduct

Help make this project welcoming and useful for contributors with different backgrounds and levels of experience.

- Be respectful, patient, and specific. Discuss code and behavior without attacking people.
- Welcome questions and constructive criticism. Explain disagreements and focus on evidence.
- Respect privacy, intellectual property, and the effort of other contributors.
- Do not harass, threaten, discriminate, or publish another person's private information.

Maintainers may edit or remove contributions, close discussions, or restrict participation to address harmful behavior. For a conduct concern, contact the maintainer using the contact options on the [maintainer's GitHub profile](https://github.com/kevinxucs). If a private contact option is unavailable, request one without posting personal details publicly.

This code applies to this repository's issues, pull requests, reviews, and other project-managed spaces.
